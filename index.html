  • Strict dependency flow: Api → Infrastructure → Application → Domain, with Repository + Unit of Work, the Specification pattern, and a Result type instead of exceptions

  • SQL Server + Redis (response cache & baskets) orchestrated with docker-compose, Swagger, user-secrets and healthchecked services
  • 182 xUnit tests (counted from source) across API, Application, Domain and Infrastructure layers, with coverage collected in CI
